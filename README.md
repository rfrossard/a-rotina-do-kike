# A Rotina do Kike

Jogo infantil responsivo que transforma a rotina diária em missões, pontos, avatares e recompensas.

## Site público

https://a-rotina-do-kike.rfrossard.chatgpt.site

## Recursos

- aventuras para manhã, banho, volta da escola, exercícios e ajuda em casa;
- 20 variações rasterizadas do Kike, com cinco disponíveis inicialmente;
- loja de recompensas e desbloqueio de avatares por pontos;
- área protegida para os responsáveis configurarem missões, pontos e prêmios;
- interface adaptada para celulares e iPad.

## Desenvolvimento

Requer Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```
